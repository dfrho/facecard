# KnowMe: AI-Powered Video Business Card Platform

KnowMe aims to revolutionize professional networking through AI-generated video business cards. The platform enables users to create compelling 15-30 second video introductions that clearly communicate their skills, offerings, and needs.

## Features

- User profile creation and management
- AI script generation with personalized voice matching
- Video generation with HeyGen integration
- Social sharing and analytics

## Tech Stack

- Next.js with TypeScript
- Tailwind CSS with ShadCN components
- Prisma with PostgreSQL (coming soon)
- OpenAI integration (coming soon)
- HeyGen integration (coming soon)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
